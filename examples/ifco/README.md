# ExTS x IFCO (coming soon)

This example will apply ExTS to **IFCO** (iterative GPU / CUDA-kernel generation
and optimization) as its search-and-selection policy. IFCO is not open-sourced
yet; this example will be added once the upstream is public, packaged like the
other examples: an `exts.patch` against a pinned upstream commit, a `setup.sh`,
and one minimal benchmark script.
