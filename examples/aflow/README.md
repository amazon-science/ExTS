# ExTS x AFlow (coming soon)

This example will integrate ExTS into **AFlow** (automated agentic workflow
optimization) as its candidate-selection step, following the **controller
pattern** used by the [`gepa`](../gepa) and [`kmse`](../kmse) examples (the
original selector stays the default behind a flag). It will be packaged like the
other examples: an `exts.patch` against a pinned upstream commit, a `setup.sh`,
and one minimal benchmark script. Not yet available.
